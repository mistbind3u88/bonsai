# archive

退役したスキルの保管場所。ここに置かれたスキルは**アクティブなスキルとして扱わない**。

- `link-skills` のスキル探索対象から除外する
- `doc-check` の整合性検査対象から除外する
- 品質チェック（prettier）の対象から除外する（`.prettierignore` に `archive/` を登録）
- README の Skills 表・依存グラフには載せない

スキルを退役させるときは、ディレクトリ構造ごと `archive/` 配下へ移し、下表に退役理由を記録する。
