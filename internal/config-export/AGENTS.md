# config-export

## 前提ツール

- Git — 差分確認に使う。

## 責務の境界

- 入力対象は、実行環境のグローバル設定と `examples/<agent>/` 配下のグローバル設定サンプル。
- 出力対象は、公開サンプルとして一般化できる内容を反映した `examples/<agent>/` 配下の差分。
- 停止条件は、対象 agent を特定できない、ローカル設定を読めない、秘匿情報や個人環境情報を公開サンプルへ含める懸念がある、または一般化可否にユーザー判断が必要な場合。
- 実行中のエージェントに残す判断は、各項目を `反映可能`、`ローカル専用`、`対象外`、`要確認` に分類し、公開サンプルへ入れる形へ一般化すること。

## サンプル化の基準

- 公開リポジトリへ置ける汎用ルールだけを反映する。
- token、API key、secret、private repository URL、社内 URL、内部ホスト名、個人の絶対パス、個人名は反映しない。
- agent 固有の CLI、skill、承認方針は、その agent のサンプルにだけ反映する。
- 実行環境に存在しないツール前提は、無条件の必須ルールとして反映しない。
