# config-import

## 前提ツール

- Git — リポジトリ内サンプルの確認に使う。

## 責務の境界

- 入力対象は、`examples/<agent>/` 配下のグローバル設定サンプルと、実行環境のローカルグローバル設定。
- 出力対象は、現在の agent と実行環境の用途に合う内容だけを merge したローカルグローバル設定。
- 停止条件は、対象 agent を特定できない、merge 先が不明、既存設定との矛盾がある、ホーム配下への書き込み承認がない、または採用可否にユーザー判断が必要な場合。
- 実行中のエージェントに残す判断は、各項目を `採用`、`不採用`、`既存優先`、`要確認` に分類し、既存設定を壊さない merge 方針を決めること。

## 取り込みの基準

- サンプルの内容は現在の実行環境に合うものだけを取り込む。
- 未導入ツール、別 agent、使わない skill、未置換プレースホルダを前提にした項目は取り込まない。
- 既存設定と同じ趣旨の項目は、重複させず既存見出しへ統合する。
- token、API key、secret、private repository URL、社内 URL、内部ホスト名は取り込まない。
