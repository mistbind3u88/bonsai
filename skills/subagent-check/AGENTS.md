# subagent-check

## 前提ツール

- 実行環境のサブエージェント一覧・結果取得手段。起動上限は実行環境の表示またはツール定義から確認する。

## 責務の境界

- 入力対象は、依頼文案、既存担当の状態・役割・再利用方針、実行環境の起動上限と利用可能な操作。
- 出力対象は、依頼境界と起動可否の判定、および呼び出し元が次に取る行動。
- 依頼境界が不足する場合は `FIX_PROMPT`、起動余剰や再利用可否を確認できない場合は `REUSE` / `WAIT` / `ASK_USER` のいずれかを返し、新規起動可とは扱わない。
- サブエージェントの起動そのものは呼び出し元スキルに任せ、このスキルは起動前の状態確認と依頼文の委譲境界確認を担う。
- 依頼文に `work_unit` / `role` / `reuse_policy` が含まれることを確認し、同じまとまった作業内の同じ役割では既存サブエージェントの再利用を優先する。
- 完了済みサブエージェントがある場合は、実行環境で利用できる結果取得操作で結果を回収し、同じ `work_unit` で再利用予定がないものだけ close 判断を行う。
- 終了ツールがない環境では、SKILL.mdの省略条件に従って完了済み担当を保持する。結果回収、再利用判断、起動枠の確認は省略しない。
- 起動可否は `OK` / `REUSE` / `WAIT` / `ASK_USER` / `FIX_PROMPT` のいずれかで返し、呼び出し元が次に取る行動を明確にする。
- `FIX_PROMPT` は、サブエージェントへの依頼文にメインエージェントが実行中のスキル名、サブエージェントの限定タスク、返すべき結果、メイン側に残す該当判断が揃うように修正する判断として返す。依頼文の境界が曖昧な場合は、起動余剰や再利用可否より `FIX_PROMPT` を優先する。
