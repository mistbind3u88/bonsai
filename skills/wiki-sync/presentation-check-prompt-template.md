# wiki-sync 体裁・関連ドキュメント整合確認テンプレート

更新した wiki が対象リポジトリの wiki schema、読み手向けの体裁、関連ドキュメントと整合しているか確認するサブエージェントに渡す。

## 境界確認メタ情報

- 実行中のスキル: `/wiki-sync`
- 依頼境界: メインエージェントが `/wiki-sync` の体裁・関連ドキュメント整合確認を実行中であり、サブエージェントの役割は指定基準への適合状況を返すこと
- 返すべき結果: 基準への適合・不整合の一覧
- メイン側に残す判断: wiki または近いドキュメントの更新判断、再確認要否、ユーザー報告
- サブエージェントが行うこと: 更新した wiki、wiki schema、関連ドキュメントを読み、体裁・構成・文脈・関連ドキュメントとの整合を確認する
- サブエージェントがメイン側に残すこと: スキル実行、wiki 編集、commit、push、ユーザーへの最終判断

## 対象

- リポジトリ: `<absolute-repo-path>`
- 更新した wiki: `<absolute-wiki-page-path>`
- wiki schema: `<absolute-schema-or-agents-path>`
- 関連ドキュメント: `<absolute-related-doc-paths-or-none>`
- 関連コード: `<absolute-related-code-paths-or-none>`

## 確認観点

| 観点                   | チェック内容                                                                                    |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| schema 整合            | 対象リポジトリの wiki schema、ページ構成、文体に合っているか                                    |
| 読み手向けの体裁       | 人間の読み手がプロダクトやビジネスの文脈を短時間で掴める見出し、導入、用語、前提、参照先か      |
| 知識への蒸留           | 判断背景、設計意図、運用上の注意点として書かれているか                                          |
| 関連ドキュメントの役割 | README / AGENTS.md / PR本文 / 作業メモの内容が、wiki として読む価値のある知識へ蒸留されているか |
| 近傍ドキュメント反映   | 局所的な制約や実装近傍で読むべき情報が、近いドキュメントやコードコメントへ反映されているか      |

## 出力形式

観点ごとに `OK` / `要修正` を示す。`要修正` の項目は以下を添える。

- 対象箇所
- 問題の種類（`schema不整合` / `体裁不足` / `実装説明寄り` / `再掲` / `近傍反映不足` など）
- 根拠
- 修正方針

観点ごとの判定と修正方針に絞って返す。
