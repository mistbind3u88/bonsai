# push

## 前提ツール

- [git](https://git-scm.com/)
- [gh](https://cli.github.com/) — `brew install gh`

## 責務の境界

- 入力対象は、対象ブランチ、未コミット変更の有無、ユーザーが承認したpush範囲、適用ルール、品質チェック結果。
- 出力対象は、承認済み範囲のpush結果と、必要な場合のPR進捗コメントへの委譲。
- 停止条件は、未コミット変更がある場合、pushの許可・依頼範囲を確認できない場合、または必要な品質チェックが通過していない場合。
- 品質チェックは `/check`、コンフリクト解消時のPRコメントは `/pr-progress` に委譲する。ブランチの直接push許可と実行権限は実行中のエージェントが確認する。
- main / masterへの直接pushが明示的に許可されている場合は、その指示を優先する。品質チェックや実行環境の権限制約は維持する。
