# subagent-review

## 前提ツール

- [git](https://git-scm.com/)

## 責務の境界

- 入力対象は、base/headの差分、未コミット変更、適用ルール、既知のレビュー判断。
- 出力対象は、同セッションのサブエージェントによる読み取り専用の差分レビュー結果。
- 停止条件は、検査入力・起動枠・モデル設定を確認できない場合、レビュー自体を完了できない場合、または指摘へのユーザー判断が揃っていない場合。
- 過去のreview判断の参照と記録は `/review-log`、起動前確認と再利用方針の決定はメインエージェント、結果通過時のタグ設置は `/mark review-sub` へ委譲する
- レビュー指摘の最終判断（修正する／対応不要）と整理・報告はメインエージェントが担う。サブエージェントの役割は差分レビューの実行に限定する
- 同じbase/head系統の修正後再レビューでは、`work_unit: subagent-review:<base>..<head>` / `role: diff-review` の既存サブエージェントを再利用する
- Codex上のモデル選択と起動引数は、SKILL.mdの「Codex上でのモデル解決」に従う。ユーザーが明示したローカル定義も設定ソースとして扱い、CLIモデル名とサブエージェントの許可モデルを個別に確認する。
- 同じbase/head系統の再レビューでも、既存サブエージェントのモデルが今回解決した目標値と一致しない場合は再利用しない

## 実行環境の違い

- 起動・再利用・待機・終了操作は、実行時のツール定義に従う。終了ツールがない環境では、検査結果を回収して再利用予定を確認し、完了済み担当として保持する。終了したとは報告しない。
- 呼び出し元のスキル名、限定タスク、返す結果、メイン側に残す判断を依頼文に含める。サブエージェントへスキル進行・採否・markを委譲しない。

## サブエージェント依頼

サブエージェントへの依頼は [subagent-prompt-template.md](subagent-prompt-template.md) を埋めて作成する。テンプレートの境界確認、レビュー観点、出力形式、`work_unit`、`role`、`reuse_policy` を削らず、差分レビューに必要なbase / head / 変更概要 / hunk-level diffを具体値で埋める。
