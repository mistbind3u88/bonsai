# r

## 前提ツール

- [git](https://git-scm.com/)

## 責務の境界

- 指定されたドキュメント、ルール、差分、コミット、会話上の前提を read-only で読み直し、現在の理解を更新する。
- 読み直しに必要な範囲で `Read` / `Grep` / `Glob` と read-only の git コマンドを使う。
- 変更、外部操作、GitHub 操作、commit、push、サブエージェント起動は対象外として扱う。
- 後続に実行する skill の選定は、このスキルの責務に含めない。

## 読み直し方針

- 読み直した対象、更新された理解、以前の理解との差分、注意点、未確認事項を分ける。
- 以前の説明や会話上の前提とズレた点は、何がどう変わったかを明示する。
- 推測は推測として扱い、確認できた事実と分けて報告する。
