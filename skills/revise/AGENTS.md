# revise

## 前提ツール

- なし。

## 責務の境界

- 入力対象は、未解決の直近提案またはユーザーが明示参照した提案と、それに対するユーザーの差し戻し・条件追加・別案要求、または呼び出し側が再検討部分だけを切り出した応答。
- 出力対象は、差し戻し対象、見直す点、再提案時に守る条件、未確認事項の整理結果。
- 停止条件は、どの提案を見直すべきか特定できない、差し戻し内容が相互に競合している、または再提案条件が不明確で補足確認なしでは整理できない場合。
- 実行中のエージェントに残す判断は、再提案を一案に絞るか複数案にするか、未確認事項を先に確認するか、どこまでを制約として確定するか。

## 解釈基準

- 新しい条件、制約、別案要求、前提否定を含む応答は再検討要求として扱う。
- 条件付き承認は、実質的に提案修正要求なのでこのスキルで扱う。
- 条件付き承認そのものは、呼び出し側が全文をこのスキルへ渡してよい。
- 承認済み部分と再検討部分が明確に混在している場合は、呼び出し側が再検討部分だけを明示的に切り出している場合に限り、その部分だけを対象化する。
- 差し戻し対象を一意に特定できない場合は、再提案方針を確定しない。
- 提案の直後に進捗報告や確認メッセージが挟まっている場合は、それらではなく未解決の提案本体を優先して読む。
- 混在応答の承認部分は、このスキルの出力へ持ち込まず、呼び出し側で別途 `approve` 対象として扱う。
