# diff-comment

## 前提ツール

- [GitHub CLI](https://cli.github.com/) — `brew install gh`

## 責務の境界

- PR diff 上の対象行へ、レビュー時だけ必要な意図・背景・判断材料を inline comment として投稿する
- PR 全体の進捗、force push 後の差分、コンフリクト解消の経過は対象外として扱う
- 既存レビューコメントへの返信は対象外として扱う
- PR/Issue 本文の作成・更新は対象外として扱う
- 将来の保守にも必要な説明は、ソースコードのコメント、README、設計ドキュメント、LLM Wiki のいずれか適切な場所へ反映する

## コメント方針

- 読み手はレビュアーであるため、diff の読み取りだけでは判断しづらい意図・背景・レビュー観点を書く
- その行で採用した判断、残した互換性、レビューしてほしい影響を、実装の逐語説明より優先して書く
- コメントは対象行に直接結び付く内容にする
- コメント本文は公開 PR に残る前提で書く
