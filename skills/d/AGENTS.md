## 前提ツール

- [git](https://git-scm.com/)

## 責務の境界

- このスキルは、企画・開発相談の開始時に read-only の情報収集を行い、目的、前提、未確認事項、論点、選択肢、次に使う skill を整理する責務を持つ。
- 質問へ直接回答するだけで足りる場合は `/q` へ案内する。
- GitHub Issue / PR の状態確認は `/gh-read`、開発開始は `/start-dev`、ドキュメント更新は `/doc-sync`、LLM Wiki 反映は `/wiki-sync`、Issue / PR 作成・更新は `/gh-edit` へ案内する。
- このスキルはファイル編集、Issue / PR 作成、commit、push、サブエージェント起動を行わない。
