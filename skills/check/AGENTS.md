# check

- [git](https://git-scm.com/)

## 責務の境界

`check` は HEAD が品質チェックを通過していることを担保する。各検査そのものは持たず、対応するスキルへ委譲して結果を集約する。ドキュメント整合は `/doc-check`、適用ルールへの適合は `/rule-check` が担う。

レビューや検査から返った指摘の採否判断は、メインエージェントが担う。指摘をそのまま自動修正せず、差分、適用ルール、責務境界、テンプレート契約、mark 条件、README 依存図との整合を確認する。対応すると別の整合指摘を誘発してループする場合や、今回の目的を超える任意改善である場合は、対応しない判断と理由を最終報告に残す。
