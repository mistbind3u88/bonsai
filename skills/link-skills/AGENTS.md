# link-skills

## 前提ツール

- 対象エージェント（CodexまたはClaude Code）とスキル一覧の確認手段。
- Windowsではコマンドプロンプトの `mklink`、macOS / Linuxでは `ln` などの標準コマンド。

## 責務の境界

- 入力対象は、公開スキルの配置、対象エージェント、OS、既存の登録先とリンク先。
- 出力対象は、公開スキルの登録用リンクと、リンク先・対象エージェントでの読込確認結果。
- 停止条件は、対象環境を手順で扱えない場合、既存配置の選択が必要な場合、または必要な権限や読込確認手段が不足する場合。
- 既存登録の削除、非公開の保守スキルの登録、エージェント指示ファイルの作成は対象外。登録先の選択と権限確認は実行中のエージェントが担う。
