# approve

## 前提ツール

- なし。

## 責務の境界

- 入力対象は、未解決の直近提案またはユーザーが明示参照した提案と、それに対するユーザーの承認応答、または呼び出し側が承認部分だけを切り出した応答。
- 出力対象は、承認対象、次に進めてよい範囲、承認に含まれない未確認事項の整理結果。
- 停止条件は、どの提案を承認したか特定できない、混在応答なのに承認部分だけが切り出されていない、または複数提案のどれを承認したか判断できない場合。
- 実行中のエージェントに残す判断は、承認後に実際にどこまで実行するか、個別の実行承認が別途必要か、未確認事項を先に解消するかどうか。

## 解釈基準

- 新しい条件、制約、別案要求、前提否定が含まれる応答は、呼び出し側が承認部分だけを明示的に切り出している場合に限り、その部分だけを扱う。
- 短い同意表現でも、対象提案が一意に特定できる場合だけ承認として扱う。
- 提案の直後に進捗報告や確認メッセージが挟まっている場合は、それらではなく未解決の提案本体を優先して読む。
- 実行承認と提案承認は分けて扱う。
- 混在応答の再検討部分は、このスキルの出力へ持ち込まず、呼び出し側で別途 `revise` に回す。
