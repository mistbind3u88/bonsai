# approve

## 前提ツール

- なし。

## 責務の境界

- 入力対象は、直前のエージェント提案と、それに対するユーザーの承認応答。
- 出力対象は、承認対象、次に進めてよい範囲、承認に含まれない未確認事項の整理結果。
- 停止条件は、どの提案を承認したか特定できない、承認応答に条件追加や差し戻しが混ざっている、または複数提案のどれを承認したか判断できない場合。
- 実行中のエージェントに残す判断は、承認後に実際にどこまで実行するか、個別の実行承認が別途必要か、未確認事項を先に解消するかどうか。

## 解釈基準

- 新しい条件、制約、別案要求、前提否定が含まれる応答は純粋な承認として扱わない。
- 短い同意表現でも、対象提案が一意に特定できる場合だけ承認として扱う。
- 実行承認と提案承認は分けて扱う。
