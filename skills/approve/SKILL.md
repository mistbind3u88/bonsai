# approve

直前のエージェント提案に対するユーザーの承認を受け取り、承認対象と次に進めてよい範囲を整理する。

## 手順

### 1. 承認対象の提案を特定する

会話中の直前のエージェント提案から、ユーザーが承認した対象を特定する。提案内に複数の選択肢、複数の操作、または段階的な実行案がある場合は、どこまでが承認対象かを分けて読む。

### 2. ユーザー応答が純粋な承認かを確認する

ユーザー応答を読み、次のいずれに当たるか確認する。

- そのまま進めてよいという承認
- 新しい条件が付いた条件付き承認
- 別案要求や前提の差し戻しを含む再検討要求
- 対象不明の短文

条件追加、別案要求、前提否定が含まれる場合は、このスキルでは承認として確定せず、`revise` の対象として扱う。

### 3. 承認範囲と未確認事項を整理する

承認として扱える場合は、次を整理する。

1. 承認された提案
2. そのまま進めてよい次アクション
3. 承認に含まれていない未確認事項

未確認事項には、権限承認、未合意の副作用、比較対象として残っている別案などを含める。

### 4. 結果を返す

以下の形で簡潔に返す。

```text
approve:
  承認対象: <どの提案を承認したか>
  次に進めてよいこと:
  - <実行してよい次アクション>
  未確認事項:
  - <承認に含まれない事項。なければ「なし」>
```

## 注意

- このスキルは提案承認を整理する。push、force push、外部投稿、破壊的操作などの実行承認そのものを代替しない
- 条件付き承認や差し戻しは、このスキルで承認確定せず `revise` の対象として扱う
- 承認対象を特定できない場合は、承認済みとして扱わない
